Content Intelligence Platform

What makes a social video break out, and where should the paid budget go? Raw platform exports become a tested SQL warehouse, an LLM tags every caption, a model scores breakout odds before posting, and a media mix model reallocates spend. Every number below is computed by the pipeline on .

Layer 1 · Warehouse

What the content is doing

Layer 2 · AI tagging

Turning captions into features

Each caption is classified into a fixed taxonomy (theme, hook, tone) by an LLM with a strict JSON contract, cached by caption hash, with a keyword-rules fallback. Accuracy is measured against a labeled holdout so the LLM has to beat the cheap baseline to justify its cost.

Layer 3 · Machine learning

Predicting breakouts before posting

Gradient boosting on pre-publish features only (tags, format, length, timing, creator collab), validated on the most recent weeks with a time-based split, the way it would be used in production.

Holdout performance

What drives the prediction

Permutation importance: drop in ROC-AUC when a feature is shuffled.

Layer 4 · Marketing mix model

Where the paid budget should go

Weekly conversions are modeled as baseline + trend + seasonality + organic reach + each channel's spend with carryover (adstock) and diminishing returns (saturation). The data generator knows the true channel effects, so the estimates can be checked against them.

Layer 5 · AI analyst

Ask the warehouse a question

Natural language becomes SQL, which passes guardrails (single read-only SELECT, allow-listed tables, enforced row limit) before it runs. These answers were generated by the pipeline from python -m ciq ask "…".

Data quality

Tests that gate every run

Blocking tests stop the pipeline before bad data reaches a model or this page. Warnings are tracked. The raw exports include duplicate rows, inconsistent platform names and glitched metric snapshots on purpose, and staging fixes them.

Synthetic data with planted effects so results can be validated. Built with Python, SQL (DuckDB or SQLite), scikit-learn, SciPy and the Anthropic API.
